# 作業 5：向量相似度實驗

本專案已成功在 `HW5` 分支中實作了一個**向量相似度實驗系統**。利用 OpenAI `text-embedding-3-small` API 將多組句子轉換為 1536 維的向量，並自行實作 Cosine Similarity 演算法計算句子間的相似度。

## 📁 檔案清單與功能說明
1. **向量與相似度函式庫**：[lib/embeddings.js](file:///home/coder/Codebase/kaochenlong/lib/embeddings.js)
   * 封裝 `embed(text)` 呼叫 OpenAI API 取得向量，以及 `cosineSimilarity(vecA, vecB)` 計算 Cosine 相似度分數。
2. **實驗測試程式**：[scripts/similarity-test.js](file:///home/coder/Codebase/kaochenlong/scripts/similarity-test.js)
   * 定義 3 組不同的測試句子，呼叫函式庫計算每組句子間的兩兩相似度並列印結果。

## 📊 實驗結果與兩兩相似度數值

執行 `node scripts/similarity-test.js` 的真實輸出數據如下：

*   **[句子 2]**: `"咖啡的香氣很迷人"`

    *   `[句子 2]` vs `[句子 3]` 相似度：`0.54729`

### 📌 第二組：意思不同的句子
*   **[句子 1]**: `"高鐵快要進站了"`

## 💡 結果分析與說明

- **符合預期分析**：  
  第一組（意思相近的句子）的兩兩相似度落在 **`0.54` 至 `0.73`** 之間（平均約 `0.65`），顯著高於第二組（完全無關的句子）的 **`0.18` 至 `0.38`**（平均約 `0.26`）。這說明 Embeddings 向量對於同主題、同語意的內容有非常強烈的空間聚集特徵，即便遣詞用字不同（例如「香氣迷人」與「喝一杯」），依然能識別出它們都與咖啡相關，結果完全符合預期。
  
- **第三組延伸分析**：  
  第三組探討「咖啡的味道」與「茶葉的味道」相似度高達 `0.73997`，這是因為它們在句構與語意主題上高度對稱（都表達對某飲品的喜好）；而這兩句與「咖啡和茶是我生活不能缺少的調劑」的相似度分別為 `0.63` 與 `0.56`，精準反映出兩者都被包含在第三句的綜合敘述之中。
